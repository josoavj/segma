Versions

Les installateurs de Segma pour Linux et Windows sont publiés dans GitHub Releases. Choisissez la version adaptée à votre système et suivez les instructions jointes à sa release.

Ouvrir les releases GitHub Code source

Linux

Ouvrez la release GitHub et choisissez l’archive ou le paquet Linux indiqué dans les fichiers de la version.

Trouver le build Linux

Windows

Ouvrez la release GitHub et choisissez le paquet Windows indiqué dans les fichiers de la version.

Trouver le build Windows
La page GitHub Releases est la source de référence pour les fichiers téléchargeables, les notes et les consignes propres à chaque version.
